# Система обнаружения аномалий в параметрах промыщленного оборудования (Проект №04)

## Участник
* **Исполнитель:** Студент №4 Мурзаянов Арслан Ирикович

## Назначение программы
Система позволяет загружать телеметрию промышленного оборудования в формате CSV, проводить валидацию данных, находить аномальные участки работы с помощью порогового метода и алгоритма машинного обучения (Isolation Forest), а также фиксировать карточки событий для подтверждения инженером по обслуживанию.

## Предполагаемый стек технологий
* **Язык программирования:** Python 3.11+
* **Анализ данных и ML:** `pandas`, `numpy`, `scikit-learn`
* **Веб-фреймворк и API:** FastAPI (с автогенерацией OpenAPI/Swagger)
* **База данных:** PostgreSQL 15+ (драйвер `psycopg2` / ORM `SQLAlchemy`)
* **Визуализация и фронтенд:** HTML/Jinja2, Plotly / Chart.js
* **Контейнеризация:** Docker, Docker Compose

## Инструкция по генерации учебных наборов данных

Для воспроизводимости испытаний (согласно п. 9.4 ТЗ) проект содержит скрипт автоматической генерации эталонного CSV-файла (10 080 записей, 12 размеченных аномалий) и 4 файлов с искусственными ошибками в директории `tests/fixtures/`.

### Запуск генерации учебного набора данных

* **На Windows:** перейдите в папку `generate_csv_files` и запустите двойным кликом файл `run_generate.py`, либо выполните в терминале:
  ```bash
  python run_generate.py
  ```
* **На Linux:** откройте терминал в папке `generate_csv_files` и выполните:
  ```bash
  python3 run_generate.py
  ```

При любом из указанных способов внутри папки `generate_csv_files` будет создано виртуальное окружение `.venv` (на ОС Linux эта папка скрытая) и в неё будут загружены необходимые библиотеки из `requirements.txt`. После этого автоматически запустится скрипт `generate_data.py` и создаст набор тестовых файлов.

## Инструкция по запуску веб-приложения

### Автоматический запуск (в 1 клик)

* **На Windows:** запустите двойным кликом файл `run_app.py` в корне проекта или выполните в терминале:
  ```bash
  python run_app.py
  ```
* **На Linux:** откройте терминал в корне проекта и выполните:
  ```bash
  python3 run_app.py
  ```

Скрипт автоматически создаст виртуальное окружение `.venv` (если оно ещё не создано), установит все зависимости из `requirements.txt`, запустит веб-сервер `uvicorn` и откроет интерфейс приложения в браузере по адресу `http://127.0.0.1:8000`.
Чтобы выключить сервер просто закройте терминал, который появился при запуске файла или в котором вводилась команда запуска, или нажмите в терминале сочетанию клавиш `CTRL + C` на клавиатуре.
